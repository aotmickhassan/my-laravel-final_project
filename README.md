

# Automated Individual Bill Generation System for University Employees

A comprehensive web application that automates the bill (invoice) generation process for university employees, leveraging a modern technology stack and featuring multilingual (Bangla) PDF document support.

---

## Features

- User authentication and secure access for university employees and admins
- Individualized bill generation and PDF download
- PDF invoices rendered in Bangla (Unicode) via mPDF
- Responsive React.js-based admin dashboard
- Robust RESTful API using Laravel backend
- Simple setup and local development using XAMPP

---

## Technologies Used

- Laravel (backend/API)
- React.js (frontend)
- Node.js, PHP, XAMPP (runtime/back-end tools)
- Bootstrap, HTML (UI/UX)
- mPDF, HTML-to-PDF (Bangla PDF invoices)

---

## Usage

- Employees log in and generate their personalized bills.
- Bills can be downloaded as Bangla-language PDFs for print or digital record.
- Admin can manage employee data and billing through dashboards.
